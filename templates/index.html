Q1

What is the difference between One-Pass and Two-Pass Assemblers?

A Two-Pass Assembler scans the source code twice: Pass 1 calculates addresses and builds the Symbol Table (SYMTAB), while Pass 2 generates machine code. A One-Pass Assembler scans the code only once, emitting machine code immediately as each statement is encountered.

Q2

How does a One-Pass Assembler solve the Forward Reference Problem?

It uses Backpatching! When an instruction references an undefined forward label, the assembler writes dummy placeholder bytes (e.g., 00 00) into memory and logs the location in a Fixup Table. The exact moment the label is encountered later in the source code, the assembler revisits the placeholder address and overwrites it with the resolved address.

Q3

How are Division (/) and Modulo (%) handled by the 8086 DIV instruction?

The 8086 DIV instruction divides the 32-bit dividend in DX:AX by a 16-bit register divisor. The hardware processor computes both simultaneously:
• The Quotient (/) is stored in AX.
• The Remainder (%) is stored in DX.

Q4

What data structures are best suited for SYMTAB and OPTAB?

A Hash Map (Hash Table / Dictionary) is ideal because it provides average O(1) constant time complexity for insertions and lookups. This enables instant mnemonic lookup and label resolution during single-pass code generation.

Q5

What is the purpose of LITTAB (Literal Table)?

LITTAB tracks literals (constant values prefixed with =, e.g. =10). Unlike immediate values embedded directly in instruction bytes, literals are allocated their own distinct memory addresses in a literal pool when directives like LTORG or END are processed.
